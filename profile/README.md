## The leaderboard for people whose agents never sleep.

Bloodrank scores AI vampires on the blood they drink and the things they actually ship. Tokens alone
don't make you an Ancient.

> **AI vampire** *(n.)* A builder who runs several AI coding agents at once and skips sleep because an
> idle agent feels like lost money.

---

## Two things, and which is which

| | What it is | Status |
| :--- | :--- | :--- |
| **Site** | [bloodrank.pages.dev](https://bloodrank.pages.dev): the scoring model, the rank calculator, `llms.txt`. | `LIVE` |
| **Bloodrank** | The service: `npx bloodrank`, verified kills, public boards, covens, plans. | `PLANNED` |

The leaderboard and the live counts on the site are sample data, and the site says so. There is no
package on npm yet and nothing is charged.

---

## Vampire Score, 0 to 1000

| Weight | What it measures |
| :--- | :--- |
| **Blood** 40% | Monthly AI spend and tokens across every agent, log-scaled so a $40K whale can't bury a sharp builder on $400 |
| **Kills** 40% | Deploys, launches, merged features, verified MRR. Proven through GitHub and Stripe, never self-reported |
| **Night** 20% | Parallel agents, the longest unbroken session, and usage between midnight and 5am. Style points only |

`Thrall` 0–149 · `Fledgling` 150–349 · `Nightwalker` 350–549 · `Elder` 550–749 · `Ancient` 750–899 · `Count` 900+

Every profile also has a **Sunlight** board: days fully offline. The essay that coined the term was about
burnout, and the best vampires last for centuries.
