# .github

The GitHub organisation profile for Bloodrank: `profile/README.md` is what
[github.com/Bloodrank](https://github.com/Bloodrank) shows.

`assets/org-banner.png` and `assets/org-avatar.png` are rendered in
[`Bloodrank/website`](https://github.com/Bloodrank/website) by
`tools/render-og.sh` (the banner is its `assets/readme-banner.png`). The avatar
is uploaded by hand at `github.com/organizations/Bloodrank/settings/profile`;
GitHub has no API for it.
